# Choosing between one hot and label encoding

Categorical variables cannot be used directly by most machine learning algorithms, making encoding an essential preprocessing step. While One hot encoding is often considered the default choice, Label encoding is frequently used because it is simpler and more memory efficient. This experiment investigates how the choice of encoding affects different machine learning models.

## Question 

How does the choice between one hot encoding and label encoding affect different machine learning algorithms in terms of accuracy, training time, and feature dimensionality?
